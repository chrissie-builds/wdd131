The 8 Legged Web

Website Planning Document | WDD 131

1. Site Name

The 8 Legged Web

Logo concept: A simple spider icon paired with the words The 8 Legged Web.

I choose this name because I felt it was simple, memorable, clear and straight to the point about what the website is about.

Possible domain: the8leggedweb.com

2. Site Purpose

The 8 legged Web is an educational website to help vistors learn all about arachnids like spiders and tarantulas their habitat, behaviour etc.

The website will provide a home page featuring interesting facts, a species guide containing information about different spiders, and an interactive quiz page where visitors can test their knowledge. A contact page and a reference page will be added as well.

The goal is to make learning about these creatures engaging, accessible, and easy to understand.

Target Audience

  • People who are curious about spiders.
  • Students researching spider species.
  • Nature and wildlife enthusiasts.
  • Visitors who want to learn interesting facts about spiders.

3. Scenarios

  • Where do different spider species live, and what do they eat?
  • How can I test my knowledge about spiders?
  • What is an interesting spider fact that I can share with my friends?
